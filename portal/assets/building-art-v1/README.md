# AhirTools — 10 bina görseli

Bu 10 simge, kullanıcı tarafından paylaşılan Travian bina ekran görüntüleri referans alınarak **yeniden resimlenmiş** izometrik görsellerdir; özgün oyun dosyaları değildir.

Görseller şeffaf arka planlı, WebP biçiminde, birbirinden ayrı 160 × 160 piksel dosyalardır.

| Site bina kimliği | Görseldeki bina adı |
|---|---|
| sawmill | Kereste Fabrikası → Marangozhane |
| brickyard | Tuğla Fırını |
| ironfoundry | Dökümhane → Demir Dökümhanesi |
| bakery | Ekmek Fırını |
| trapper | Tuzakçı |
| palisade | Çit |
| barracks | Kışla |
| heromansion | Kahraman Kışlası |
| academy | Akademi |
| smithy | Zırh Dökümhanesi |

Başka binaların görselleri değiştirilmedi. Yerleşim: Binalar kataloğunun yanında ve hesaplama penceresi başlığında.
